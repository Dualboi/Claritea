Claritea marketing website.

A simple, professional tea brand starter built with React, Vite, and Tailwind CSS.

## Start

1. Install dependencies with `npm install`.
2. Run the app with `npm run dev`.
3. Build for deployment with `npm run build`.

## Structure

- `index.html` loads the React app.
- `src/App.jsx` contains the tea landing page.
- `src/components/` holds reusable UI pieces.
